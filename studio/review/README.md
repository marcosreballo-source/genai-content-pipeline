# Review Engine (REP generalizado)

- `lenses/`: tipos de cobrança (técnica, pedagógica, narrativa, visual, formato, público, persuasão, pesquisa, reprodutibilidade, consistência, conformidade/legal, acessibilidade, KT, fala).
- `personas/`: quem cobra. Todas começam `generic`; calibre com documentos reais e feedback real (`/rep-panel`).
- `panels/`: combinações por contexto (disciplina ICMC, defesa, simpósio, journal, competição de startup, investidor, cliente, Eldorado status/negócios/rampagem, curso KF, manual de imóvel).
