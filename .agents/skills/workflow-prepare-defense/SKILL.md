# Workflow: Preparar Defesa/Apresentação

## Quando usar
Quando o estudante precisa apresentar um trabalho ou defender TCC/projeto.

## Pré-requisitos
- Documento finalizado no assignment_repository

## Passos

1. Invocar o **Presentation Builder**: "Use o presentation-builder para criar apresentação de [tipo] a partir do trabalho [id]"
2. Revisar os slides e narrativa gerados
3. Invocar o **Oral Defense Coach**: "Use o oral-defense-coach para simular banca de [tipo]"
4. Praticar as respostas às perguntas difíceis
5. Invocar novamente o PB para ajustes se necessário
6. Repetir 3-5 até estar preparado
