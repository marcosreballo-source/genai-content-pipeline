# Workflow: Preparar para Prova

## Quando usar
Quando o estudante precisa estudar para uma avaliação.

## Pré-requisitos
- DKB da disciplina deve existir

## Passos

1. Invocar o **Exam Simulator** no Modo Professor: "Use o exam-simulator no modo professor para {codigo_disciplina}"
2. Responder às questões geradas
3. Invocar o **Exam Simulator** no Modo Tutor: "Use o exam-simulator no modo tutor para corrigir minhas respostas"
4. Revisar os materiais indicados pelo tutor
5. Repetir 1-4 até dominar o conteúdo
